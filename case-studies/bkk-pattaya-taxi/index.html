BKK Pattaya Private Taxi

A route-focused landing page and booking flow designed to turn Thailand transfer search intent into clear quote requests.

Open live demo Source code
Use case Private taxi booking funnel
Core loop Route interest to quote request
Stack TypeScript, React, tRPC, SEO

What needed to improve

Problem

Route-based taxi searches need fast trust signals, clear vehicle choices, and direct contact paths. A generic landing page would make visitors work too hard before asking for a quote.

Build

The page focuses on route intent, mobile-first booking fields, vehicle options, local transfer copy, and multi-channel contact paths through LINE, WhatsApp, Telegram, and email.

Result

The project shows practical product thinking: SEO content, conversion-focused UI, source code, and a live GitHub Pages demo are all inspectable from one page.

What to inspect

Booking path Check how quickly a visitor can move from route to quote.
Mobile layout Review the form, vehicle cards, and call-to-action density.
SEO structure Inspect route-focused copy, headings, and service framing.
Contact handoff Verify the multi-channel flow for real booking inquiries.
