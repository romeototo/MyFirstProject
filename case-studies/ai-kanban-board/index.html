AI-Powered Kanban Board

A focused planning tool that uses AI to break rough ideas into smaller tasks, then keeps the board synced and easy to move.

Open live demo Source code
Use case Personal task planning
Core loop Idea to smaller tracked tasks
Stack Vanilla JS, Firebase, Gemini AI

What needed to improve

Problem

Big tasks often stay vague, which makes it hard to decide the next move. The board needed to help turn rough work into specific actions without adding process overhead.

Build

The app pairs a simple Kanban interface with AI task breakdown, drag-and-drop movement, real-time Firestore sync, and summary analytics for quick status checks.

Result

The portfolio now presents the board as more than a screenshot: visitors can see the goal, implementation choices, live demo, and source in one focused case study.

What to inspect

AI breakdown Test whether rough ideas become smaller concrete tasks.
Board movement Move tasks across columns and check that the flow stays clear.
Cloud sync Review how Firestore keeps task state available across sessions.
